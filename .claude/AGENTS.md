# Next.js version

This project runs Next.js 14.2.35 (App Router; see `node_modules/next/package.json`). Conventions differ from newer majors — notably, request interception lives in `middleware.ts` (not `proxy.ts`). Check the existing code and the installed version's behavior before writing anything, and heed deprecation notices in build output.
